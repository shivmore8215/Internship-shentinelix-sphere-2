## 1. Abstract

Cyber Sentinel is a specialized security tool designed to detect and monitor unauthorized keylogging activities on a computer system. In an era where data privacy is paramount, keyloggers pose a significant threat by silently capturing user keystrokes to steal sensitive information such as passwords, credit card numbers, and personal messages. This project aims to provide a user-friendly, real-time detection mechanism that identifies suspicious processes and alerts the user, thereby enhancing system security.

## 2. Problem Statement

Keyloggers are a form of spyware that can run in the background without the user's knowledge. Traditional antivirus software may sometimes miss specific custom or lightweight keylogging scripts. There is a need for a dedicated, lightweight, and accessible tool that specifically targets the behavioral patterns and signatures of keylogging processes to provide an additional layer of security.

## 3. Objectives

The primary objectives of the Cyber Sentinel project are:

- **Real-time Detection:** To scan running system processes and identify potential keyloggers based on known signatures and behavioral patterns.
- **User Alerting:** To immediately notify the user upon detecting a threat.
- **Process Management:** To provide users with the ability to identify and terminate malicious processes.
- **Activity Logging:** To maintain a persistent history of detected threats for forensic analysis.
- **User-Friendly Interface:** To offer a modern, web-based dashboard for easy monitoring and management.

## 4. System Architecture

The system follows a client-server architecture, utilizing a local web server to host the user interface and a backend engine for system-level operations.

### 4.1. Backend (Python)

- **Core Logic (`detector.py`):** Utilizes the `psutil` library to iterate through system processes. It inspects process names and command lines against a predefined list of suspicious signatures (e.g., "keylogger", "hook").
- **Web Server (`server.py`):** Built with **Flask**, a lightweight WSGI web application framework. It exposes API endpoints for the frontend to request scans, retrieve logs, and manage processes.
- **Data Storage:** Uses a JSON file (`detection_logs.json`) for persistent storage of detection history, ensuring logs survive system restarts.

### 4.2. Frontend (HTML/CSS/JS)

- **Dashboard (`index.html`):** A responsive web interface designed with modern aesthetics (Inter font, FontAwesome icons).
- **Styling:** Custom CSS (`style.css`) providing a clean, professional look with visual indicators for system status (Safe/Threat Detected).
- **Interactivity:** JavaScript (`script.js`) handles asynchronous API calls to fetch real-time data without reloading the page.

## 5. Features

- **Live System Scanning:** Scans all active processes for keywords associated with keylogging tools.
- **Interactive Dashboard:** Displays the current system status ("System Secure" or "Threat Detected") and lists active threats with their Process ID (PID) and command line details.
- **Persistent Logs:** A dedicated "Logs" section tracks the history of all detection events (Threat Detected, Threat Removed) with timestamps.
- **Process Termination:** The backend supports terminating malicious processes (via API), empowering users to take immediate action.
- **Visual Feedback:** The UI changes state (colors, icons) based on the threat level, providing immediate visual cues.
